# NetWatch v0.1.0-beta.1

First beta of NetWatch, a network monitoring plugin for **TrafficMonitor 1.86 x64 on Windows 10/11 x64**. Plugin Management displays version **0.1.0**.

## Features

- Group devices and services under a short label and status circle on the taskbar.
- Check availability with ICMP, TCP or HTTP/HTTPS. Up to four checks run at once.
- See each check's state, response time, last error and check time in settings. Manual tests do not change monitoring history.
- Import hosts from a local OpenSSH config. The preview lets you choose hosts and skips duplicates. Imported entries check TCP ports; they do not log in over SSH.
- Start with empty LOCAL, WEB and SSH groups, then add your own targets.
- Use the interface and offline help in English, Russian, Simplified Chinese or Traditional Chinese.

This build also fixes repeated "Invalid argument" dialogs after importing several hosts. NetWatch now limits its contribution to TrafficMonitor's tooltip.

## Install

Install the latest Microsoft Visual C++ v14 x64 Redistributable, exit the intended TrafficMonitor instance, and copy `NetWatch.dll` from the ZIP to its `plugins` directory. Back up `NetWatch.conf` when updating. Start TrafficMonitor, configure NetWatch, Save, restart after layout changes and enable the new items in TrafficMonitor's own **Display settings**.

The ZIP includes installation guidance, both license texts, third-party notices, verification details and a manifest. `SHA256SUMS.txt` is a separate release asset. No personal configuration, runtime installer or TrafficMonitor executable is bundled.

## Verification and limitations

All **9 automated tests pass**. They cover settings behavior, the DLL interface, GDI drawing, translations, configuration changes, local network checks, TLS rejection and unloading during active checks. The DLL extracted from the release ZIP also passed the interface and tooltip tests. Details and hashes are in [the verification record](https://github.com/Lay007/trafficmonitor-netwatch/blob/master/docs/verification.md).

The new settings table still needs a desktop layout check. D2D, different DPI settings and themes, long runs, sleep/wake, and a successful HTTPS request to a controlled server with a trusted certificate have not been fully tested. Other TrafficMonitor versions and architectures have not been checked. Please treat this as a test build.

Report issues with versions, DPI, reproduction steps and redacted diagnostics at [GitHub Issues](https://github.com/Lay007/trafficmonitor-netwatch/issues).
