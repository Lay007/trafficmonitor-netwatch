# NetWatch v0.1.0-beta.1

Initial feedback prerelease for **TrafficMonitor 1.86 x64 / Windows 10 and 11 x64**. The DLL reports numeric plugin version **0.1.0**; the distribution is explicitly marked as a prerelease.

## Features

- User-defined groups with persistent UUIDs, short taskbar labels and availability circles.
- ICMP, TCP and HTTP/HTTPS checks with bounded workers, launch rate and total I/O budgets.
- Live per-check state, typed time, raw errors and last-check timestamp in settings; manual draft tests remain separate.
- Local OpenSSH Host import with preview, selection and duplicate handling. Imports TCP endpoint checks without login, keys or commands.
- Empty LOCAL, WEB and SSH defaults, independent monitoring/visibility, and restart reminders for display changes.
- English, Russian, Simplified Chinese and Traditional Chinese UI and offline help.
- Bounded plugin tooltips to avoid repeated MFC invalid-argument errors after importing many hosts.

## Install

Install the latest Microsoft Visual C++ v14 x64 Redistributable, exit the intended TrafficMonitor instance, and copy `NetWatch.dll` from the ZIP to its `plugins` directory. Back up `NetWatch.conf` when updating. Start TrafficMonitor, configure NetWatch, Save, restart after layout changes and enable the new items in TrafficMonitor's own **Display settings**.

The ZIP includes installation guidance, both license texts, third-party notices, verification details and a manifest. `SHA256SUMS.txt` is a separate release asset. No personal configuration, runtime installer or TrafficMonitor executable is bundled.

## Verification and limitations

The source's recorded full suite passed **9/9 tests** after the live table addition. It covers native hidden dialog/controller behavior, actual DLL ABI and GDI drawing, localization, configuration and generation changes, loopback probes, rejection of untrusted TLS and worker/module lifetime. See [the verification record](https://github.com/Lay007/trafficmonitor-netwatch/blob/master/docs/verification.md) for precise evidence and hashes.

The new table's desktop layout has not been visually inspected because the computer-use helper was unavailable. D2D, the full DPI/theme/font matrix, long-duration behavior, sleep/wake and a controlled trusted-CA HTTPS success fixture remain open. Other host versions/architectures are not certified. This is a feedback prerelease, not a claim of complete compatibility testing.

Report issues with versions, DPI, reproduction steps and redacted diagnostics at [GitHub Issues](https://github.com/Lay007/trafficmonitor-netwatch/issues).
